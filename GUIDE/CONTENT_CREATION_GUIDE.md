# Content Creation Guide

## 目的
このリポジトリは、**自分が毎日チェックしやすい個人向けの技術ニュース知識ベース**として運用しています。

Xから集めた情報を、ただ集めるだけでなく、**「読む価値がある」** 状態で整理・蓄積することを目指します。

## 基本方針

- **量を固定しない**：その日に重要な情報が多ければ多めに、少なければ少なくても問題ない。
- **重要な情報はできるだけ網羅する**：特に影響が大きそうなものや、新規性・示唆のあるものは優先的に拾う。
- **情報の性質を明記する**：Xの情報は噂・コミュニティ議論・公式情報などが混在するため、性質を区別して書く。
- **毎日更新しやすいクオリティを保つ**：読みやすく、価値が伝わるまとまりにする。

## 情報の選定基準

以下の観点で情報を選ぶ：

- **重要性**：その情報が業界や自分の関心領域に与える影響は大きいか
- **新規性**：新しい動き、発表、発見か
- **示唆・示唆性**：単なる事実ではなく、背景や今後の意味が読み取れるか
- **実用性・関連性**：自分の興味（特に生成AI・IP制作関連）や学びにつながるか

ノイズや重複が激しい場合は適度に整理するが、**重要なものは漏らさない**ことを優先する。

## X情報の扱い方（重要）

Xの投稿は信頼度が様々であるため、以下のように性質を明記する：

- **公式発表・一次情報**：公式アカウントや信頼できる情報源からの発表
- **コミュニティでの議論・話題**：複数の投稿で取り上げられている話題
- **ユーザー体験・事例共有**：実際に使ってみた、分析したなどの体験談
- **噂・憶測ベース**：明確な根拠が薄い情報（その場合は「X上で噂されている」「コミュニティで指摘されている」などの表現を使う）

例：
- 「X上でコミュニティで話題になっている」
- 「ユーザー体験として共有されている」
- 「公式発表として注目されている」

## ダイジェストの書き方

各項目は以下の構成を基本とする：

1. **タイトル**：簡潔で内容が伝わるもの
2. **内容の要約**：何が起きているか
3. **背景・文脈**（可能なら）：なぜ今注目されているか
4. **ポイント / 示唆**：この情報から何が言えるか（重要）

読み手が「なぜこれが大事なのか」を理解できるようにする。

## トーン

- 実用的でわかりやすい
- 過度にセンセーショナルにしない
- 個人向け知識ベースとして、学習や意思決定に役立つ表現を意識

## 品質の優先順位

1. **正確性・信頼性の明記**（最優先）
2. **情報の価値・示唆**
3. **網羅性**（その日の重要なものをできるだけ）
4. **読みやすさ**
