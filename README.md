### GitHub Pagesで公開する方法
1. リポジトリの **Settings** → **Pages** に移動
2. **Source** を `Deploy from a branch` に設定
3. Branch: `main` / Folder: `/ (root)` を選択
4. Save
5. 数分後に https://alignlabai-rgb.github.io/ai-news-from-x/ でアクセス可能になります
